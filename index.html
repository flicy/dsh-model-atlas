GETTING STARTED

5 分钟快速上手 DSH

从零开始，不需要任何编程基础。跟着这三步，让 DeepSeek Harness 在你的电脑上跑起来。

📦

第一步：安装 Node.js

DSH 运行在 Node.js 上。去 nodejs.org 下载 LTS 版本（左侧那个），双击安装，一路"下一步"。

💡 验证安装

安装完成后，打开终端（Mac 的"终端.app"或 Windows 的"命令提示符"），输入 node --version，如果看到 v18.x.x 或更高的版本号，就说明装好了。

🚀

第二步：启动 DSH（只需要一行命令）

在终端里输入以下命令，回车：

npx @deepseek-ai/dsh web

第一次运行会自动下载 DSH，然后启动 Web UI。终端会打印一行地址：

🌐 Web UI started at http://127.0.0.1:3080

用浏览器打开这个地址，你就能看到 DSH 的界面了。

🔑

第三步：配置模型 API Key

在 DSH 界面中，点击右上角的 设置 → 模型：

  • 已经有 TokenDance Key？ 在 DeepSeek 卡片里输入你的 API Key，保存
  • 还没有 Key？ 去 tokendance.space 注册，获取 API Key
  • 保存后，回到首页，新建一个会话，选择模型 deepseek-v4-flash，开始聊天
🎉 恭喜！

你现在已经可以跟 DSH 对话了。试试让它"总结一下这个项目"或"帮我写一个 Python 脚本"。

❓

新手常见问题

  • 端口被占用？ 用 npx @deepseek-ai/dsh web --port 3081 指定其他端口
  • 想用其他模型？ 在设置 → 模型 → 添加自定义 Provider，填上你的 API 地址和 Key
  • DSH 是什么？ 一个开源 AI Agent 框架，可以让 AI 读写文件、跑命令、自主完成任务
  • 免费吗？ DSH 本身是开源的（MIT 协议），你只需要支付模型 API 的费用
OVERVIEW

DeepSeek Harness 是什么？

一句话：一个让 AI 帮你干活的开源框架。你告诉它目标，它自己想办法完成。

🤔

它解决了什么问题？

传统的 AI 对话工具只能"聊天"——你问一句，它答一句。DSH 不一样，它给你一个虚拟工作台：

  • 读写你的文件 — 读取项目代码、修改配置文件、创建新文档
  • 在终端里跑命令 — 执行 Python 脚本、安装依赖、运行测试
  • 搜索互联网 — 查找最新信息、调研竞品、获取实时数据
  • 委派子代理 — 把一个复杂任务拆成多个子任务，并行处理
  • 记住你的偏好 — 通过持久化技能，跨会话保持一致的行为
🎯 你可以用它做什么？

代码审查、自动写测试、数据分析、文档生成、项目管理、定时任务……任何你不想亲自做的重复性工作。

COST OPTIMIZATION

Token 越来越贵，怎么省钱？

用最少的 Token 获取最大的智能，这是每个 DSH 用户的必修课。

💰

策略一：选对模型，立省 90%

不同模型的价格差异巨大，从 $0.50/M 到 $150/M 不等。核心原则：

日常对话

DeepSeek V4 Flash
$0.50/M
平均省 96%

编码任务

Qwen3.8 Max
$4.00/M
不如 Flash 时用

深度推理

Kimi K3 / V4 Pro
$5.00/M
只在必要时用

🎯 黄金法则

80% 的任务用 DeepSeek V4 Flash（$0.50/M），15% 用 Qwen3.8 Max（$4.00/M），5% 用 Kimi K3（$5.00/M）。综合成本比全部用 GPT-4o 低 95%。

⏰

策略二：利用峰谷定价

DeepSeek 采用峰谷定价——闲时（非高峰时段）价格减半：

  • 闲时（非高峰）：DeepSeek V4 Flash 仅 $0.25/M
  • 批量任务安排在闲时执行，成本直接减半
  • DSH 的 headless 模式支持脚本化批量提交，适合定时跑任务
📝

策略三：减少上下文长度

Token 费用 = 输入 Token + 输出 Token。输入 Token 通常占大头，因为包含历史对话和上下文。

  • 定期清理会话历史 — 长会话会积累大量 Token
  • 使用精确指令 — 避免在 prompt 中包含无关信息
  • 利用 DSH 的上下文压缩 — 使用 dsh-context 或 dsh-auto-compact 插件自动压缩
  • 分而治之 — 大任务拆成小任务，每个子任务用独立的短会话
🆓

策略四：善用免费额度

Groq

免费使用 Llama 3.3 70B，速度极快。适合简单任务和批量处理。

Provider: Groq Base URL: https://api.groq.com/openai/v1 Models: llama-3.3-70b-versatile
TokenDance 新用户

新注册通常赠送体验额度，可用于测试各模型效果。

PROVIDERS

模型接入方式全解析

DSH 支持 6 种模型接入方式，覆盖所有主流场景。

⚡

DeepSeek 原生

最简配置，安装后直接使用。DSH 原生支持 DeepSeek 协议，填入 API Key 即可。

Web UI: 设置 → 模型 → DeepSeek → 输入 Key → 保存
📦

内置 Provider 目录

Anthropic、OpenAI、Azure、Bedrock、Vertex、Codex 等一键配置。

点"添加 Provider"→ 选择服务商 → 填 Key
🔧

自定义 Provider

任意 OpenAI 兼容 API 端点：Grok、Together AI、Groq、vLLM、Ollama 等。

# ~/.dsh/settings.yaml llm-pi-ai: providers: groq: apiKeyEnv: GROQ_API_KEY api: openai-completions baseURL: https://api.groq.com/openai/v1 models: - id: llama-3.3-70b-versatile
🎨

多模态配置

视觉模型需声明 input 模态，支持 text + image 输入。

models: - id: vision-model input: [text, image]
🔄

聚合网关（TokenDance）

一个 Key 接入数十个模型，统一计费。当前你使用的方案。

🖥️

本地模型

通过 Ollama / vLLM 本地部署开源模型，暴露 OpenAI 兼容接口。

llm-pi-ai: providers: ollama: api: openai-completions baseURL: http://localhost:11434/v1 models: - id: llama3.3

ARCHITECTURE

DSH 架构原理

理解 DSH 的设计哲学：一切皆插件。

🧩

插件化架构

DSH 的核心由 100+ 个插件 组成，每个插件只干一件事。模型接入、文件操作、命令执行、Web UI 都是插件。

  • dsh-llm-pi-ai — 模型 Provider 接口
  • dsh-tool-bash — 终端命令执行
  • dsh-tool-fs — 文件系统操作
  • dsh-agent-loop — Agent 循环引擎

你可以在 ~/.dsh/settings.yaml 中配置所有插件的行为。

📋

配置层次

配置由三层叠加：Bundle 默认 → Profile 配置 → 用户配置（~/.dsh/settings.yaml）。用户配置优先级最高。

🔐

凭据管理

API Key 以只写方式存储在 $DSH_HOME/.credentials.yaml，Web UI 不回显。支持通过环境变量引用（推荐）。
