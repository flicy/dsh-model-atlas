OVERVIEW

DSH 模型体系概述

DeepSeek Harness 的模型接入层采用 Provider Interface 架构，任何兼容 OpenAI Chat Completions 协议的 API 都可以即插即用。

🔌

Provider 机制

DSH 通过 llm-pi-ai 插件管理模型 Provider。每个 Provider 定义 baseURL、API 协议、认证方式和模型列表。

  • 内置 Provider 目录：DeepSeek、Anthropic、OpenAI、Azure、Bedrock、Vertex、Codex
  • 自定义 Provider：任意 OpenAI 兼容的 API 端点
  • 支持 MCP (Model Context Protocol)
🔄

多模型切换

同一会话中可随时切换不同 Provider 下的模型，无需重启服务器。

  • Web UI 模型选择器一键切换
  • 设置默认模型
  • 配置多个 Provider 并行使用
🔐

凭据管理

API Key 以只写方式存储在 $DSH_HOME/.credentials.yaml，设置页面不回显密钥。

  • 支持环境变量引用（如 apiKeyEnv: TOKENDANCE_API_KEY）
  • Web UI 设置页面安全保存
  • 多 Provider 独立凭据管理
🧩

插件生态

DSH 拥有 100+ 插件包，覆盖 LLM 接入、工具调用、沙箱、会话管理、Web UI 等全部能力。

  • dsh-llm-pi-ai — 通用 Provider 接口
  • dsh-llm-deepseek — DeepSeek 原生协议
  • dsh-llm-retry — 自动重试与容错
  • 可自行开发插件扩展

CONFIGURATION

Provider 配置指南

在 DSH 中接入模型的三种方式，从易到难。

⚡
DeepSeek 官方
原生协议
最简配置，填 API Key 即可。DSH 原生支持 DeepSeek 协议，自动获取模型列表。
Web UI: 设置 → 模型 → DeepSeek 卡片 → 输入 API Key → 保存
📦
内置 Provider 目录
Anthropic / OpenAI / Azure / Bedrock / Vertex / Codex
点"添加 Provider"，选一个，填凭据。支持 Anthropic、OpenAI 等主流服务商。
Web UI: 设置 → 模型 → 添加 Provider → 选择服务商 → 填 Key → 保存
🔧
自定义 Provider
openai-completions
任意 OpenAI 兼容 API 端点：Grok、Together AI、Groq、vLLM、Ollama、中转站等。
# settings.yaml llm-pi-ai: providers: groq: displayName: Groq apiKeyEnv: GROQ_API_KEY api: openai-completions baseURL: https://api.groq.com/openai/v1 models: - id: llama-3.3-70b-versatile name: Llama 3.3 70B - id: llama-3.1-8b-instant name: Llama 3.1 8B
🎨
多模态模型配置
text + image
视觉模型需显式声明 input 模态。支持图片输入的模型会在发送前校验。
# 为单个模型添加图片支持 llm-pi-ai: providers: my-gateway: models: - id: vision-model input: [text, image] # 或为整个路由设置默认 vision-gateway: defaultInput: [text, image] models: - id: first-model - id: second-model

QUICK START

快速上手

从零开始配置 DSH 模型环境的完整步骤。

1

安装 DSH

通过 npm 全局安装，要求 Node.js 18+

npx @deepseek-ai/dsh web

或从源码构建：

git clone https://github.com/deepseek-ai/deepseek-harness.git cd deepseek-harness pnpm install pnpm run build pnpm dsh web
2

配置模型 Provider

打开 Web UI 的 设置 → 模型 页面，添加 Provider 并填入 API Key。

如需配置多个 Provider，直接在 settings.yaml 中编辑：

# 位置: ~/.dsh/settings.yaml llm-pi-ai: providers: my-gateway: displayName: 我的网关 apiKeyEnv: MY_API_KEY api: openai-completions baseURL: https://your-gateway.com/v1 models: - id: model-a name: 模型 A - id: model-b name: 模型 B
3

选择工作区

在 Web UI 中点击"选择工作区"，添加你的项目目录。只有选中工作区后，才能发送任务。

4

选择模型并开始

新建会话，在模型选择器中选择你配置的模型。DSH 会记住你的默认选择。

模型切换即时生效，无需重启服务器。

5

常用命令参考

dsh web # 启动 Web UI dsh --profile headless "任务" # 无头模式运行任务 dsh plugin --profile web # 管理插件 dsh --profile web --dump-config # 查看完整配置
